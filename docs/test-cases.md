## 7. 复现方式

```bash
# 1. 启动 MongoDB（默认 27017）
mongod --dbpath <数据目录> --port 27017 --bind_ip 127.0.0.1

# 2. 安装依赖并运行全部用例
npm install
npm test
```

只跑某一类：

```bash
node --test tests/engine.test.js        # 规则引擎
node --test tests/api.fill.test.js      # 填写与跳转
node --test tests/api.stats.test.js     # 统计
```

数据库不在默认地址时：

```bash
MONGO_TEST_URI=mongodb://127.0.0.1:27027 npm test
```
